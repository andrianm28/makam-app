# Requirements — Visitation Booking

**Status:** Optional P1/B06.

## Acceptance criteria

1. Cemetery can expose information-only or bookable visitation mode.
2. Bookable mode enforces operating hours, capacity, blackout dates, and confirmation policy.
3. Request supports visitor count, contact, accessibility needs, and optional facilities.
4. Grave/plot navigation follows data-access policy.
5. Customer receives confirmation, instructions, change/cancellation status, and fallback contact.
6. Operator sees only bookings for assigned cemetery.
7. Repeated submission does not duplicate a booking.
