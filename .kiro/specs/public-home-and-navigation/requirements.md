# Requirements — Public Home and Navigation

**Authority:** Stakeholder Workflow MVP — Home Page.

## Acceptance criteria

1. Homepage displays four primary menus in this exact order: Pemesanan Makam, Layanan Pemakaman, Perpanjangan Makam, FAQ.
2. All four are public and reachable without login.
3. Pemesanan Makam is the primary CTA.
4. Desktop and mobile navigation use the same labels.
5. Homepage includes customer-service CTA and truthful Urgent availability.
6. Feature-gated services display an explanatory state, not a dead link or generic 404.
7. Public routes follow `docs/product/information-architecture.md`.
8. Navigation is keyboard accessible and responsive.
9. Analytics records menu impression and click without sensitive data.
