# Requirements — Cemetery Operator Dashboard

**Source:** K34

## Acceptance criteria

1. Operator has a dedicated authenticated panel.
2. Operator only sees requests and orders for assigned cemeteries.
3. Operator can confirm/reject availability with mandatory note.
4. Operator can update indicative package/class availability.
5. Operator input is advisory; admin remains final authority for quote and payment opening.
6. If operator does not respond, admin manual verification path remains available.
7. All operator decisions and data changes are audited.
8. Dashboard adoption must be measurable without making workflow dependent on adoption.
