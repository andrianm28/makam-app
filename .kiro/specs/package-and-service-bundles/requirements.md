# Requirements — Package and Service Bundles

**Authority:** K26; benchmark refinement B03.

## Acceptance criteria

1. Package version defines included, optional, excluded items, quantities, units, fulfillment owner, service area/window, and evidence.
2. Published package version is immutable.
3. Quote references exact package/service/price versions.
4. Optional items become separate accepted quote lines.
5. Substitution follows configured rule and customer approval when required.
6. Completion checks fulfillment evidence for required items.
7. Package supports cemetery-, platform-, and vendor-fulfilled items.
8. UI clearly presents inclusions, exclusions, and additional charges.
