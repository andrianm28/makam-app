# v0.5 Dev+Staging Environment Update Summary

## Decision

The project accepts one Ubuntu 22.04 LTS host with 2 vCPU and 4 GB RAM for combined development and staging only.

## Added or clarified

- application/runtime version isolation through containers;
- shared PostgreSQL/Redis with strict logical isolation;
- staging-only constrained Horizon pool;
- development and batch workers on demand;
- build-off-host CI promotion;
- external object storage and provider sandboxes;
- remote staging logical backup;
- lightweight monitoring and low-memory runbook;
- scanner strategy that remains fail-closed in staging;
- capacity upgrade/split triggers;
- production remains Ubuntu 24.04/managed and separate.

## Result

The non-production environment is now cost-optimized without weakening the production baseline or allowing host package versions to drift from the pinned application stack.
