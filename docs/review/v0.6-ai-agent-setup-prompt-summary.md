# v0.6 AI-Agent Environment Setup Prompt Summary

## Purpose

v0.6 adds an executable master prompt and authorization checklist for an AI coding/operations agent to set up the Makam.co.id combined development and staging environment and developer tooling.

## Added artifacts

- `docs/operations/ai-agent-dev-stg-setup-prompt.md`
- `docs/operations/ai-agent-dev-stg-setup-variables.env.example`
- `docs/operations/ai-agent-dev-stg-execution-checklist.md`

## Scope covered

The prompt covers:

- discovery and implementation planning;
- Ubuntu host hardening;
- Docker and Compose;
- immutable PHP/Laravel image;
- PostgreSQL and Redis isolation;
- reverse proxy, DNS, TLS, and development access restriction;
- Laravel bootstrap, Horizon, scheduler, and on-demand workers;
- developer tooling, formatting, tests, static analysis, and Make/Task commands;
- CI/CD build-once/promote workflow;
- staging backup and restore test;
- lightweight observability;
- validation evidence and rollback reporting.

## Safety properties

- no production data or credentials;
- no secrets in prompt, Git, logs, or final report;
- destructive actions require human review;
- development and staging remain logically isolated;
- heavy workloads remain excluded from the 2 vCPU/4 GB host;
- the agent must distinguish actual validation from untested assumptions.
