# Triage Labels

| Label in mattpocock/skills | Label in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

**Nothing carries these labels today.** This repo has no GitHub issues, and
[`issue-tracker.md`](issue-tracker.md) keeps the "PRs as a request surface"
flag off. The vocabulary is defined so it is ready if either changes; it is not
in use.
