# ADR-0004: Gate Online Payments Behind Shared Money Path

- **Status:** Accepted from RKS

## Decision

Makam.co.id consumes K3–K5 shared journal/payment/reconciliation. Online payment remains disabled until the first product proves the complete money path and Makam.co.id merchant configuration is active.

## Interim behavior

Order, verification, quote, and status workflow operate with manual payment coordination and recorded evidence.

## Consequences

Development can deliver value before provider activation, but operations need a clear manual payment SOP and migration plan.
