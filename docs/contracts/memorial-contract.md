# Memorial and QR Contract

## Privacy modes

`PRIVATE`, `FAMILY_ONLY`, `UNLISTED`, `PUBLIC`.

## Public allowlist

Only approved display name, dates, biography, selected media, cemetery/block/plot projection according to policy, and moderated messages.

## QR

QR contains a revocable opaque token/URL, never a raw grave ID, contact, or permanent file URL.

## Controls

Consent/authority evidence, editor roles, moderation, report abuse, immediate unpublish, token rotation/revocation, and audit.
